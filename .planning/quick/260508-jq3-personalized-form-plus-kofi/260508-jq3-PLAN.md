# Per-country flight form (working endpoint) + restore Ko-fi widget

The dashboard TP widget (Klook tours, city_id=2) is broken with ad blockers
(~30% of users) — `affiliate.klook.com`/`clarity.ms`/`sentry.avs.io` get
ERR_BLOCKED_BY_CLIENT, the widget's JS then crashes on undefined.payload, and
the user sees a blank thin strip.

User asked: if we can personalize per country, keep TP widget; otherwise revert
to "search flights" button. Plus re-add Ko-fi donation widget either way.

**Third path beats both:** restore the per-country custom form (destination
pre-filled from iata-cities.ts) but point at `www.aviasales.com/search`
instead of the broken `search.aviasales.com/flights/`. Verified live: that
endpoint stays on `.com`, returns `<html lang=en>`, and accepts the same
params (destination_iata, depart_date, adults, marker, locale). Personalized
per country, ad-blocker-proof, no iframes, no Klook.
