**Ported the frozen Formula v9 Bayesian-shrinkage scorer verbatim from prototype-scorer.mjs (byte-exact parity, max |delta| = 0.0000 across 248 countries), bumped weights.json to v9.0.0, fixed vdem/GPI historical backfill vintage selection, and regenerated all 668 historical snapshots + public/scores.json.**

## Accomplishments

- `computeCountryScore` fully rewritten as the Formula v9 port: advisory consensus (frozen excluded-source set, importance tiers, at/nz rebase) -> per-pillar Bayesian shrinkage toward a region-anchored conservative prior -> weighted geometric mean + down-only acute soft-min (conflict/crime) + count-damped severe-advisory modifier -> concave 1-10 calibration -> new `confidence` output field. All v8.x mechanisms removed from the score computation: eligibility gates, neutral-0.5 pillar defaults, low-data advisory blend, critical floor, majority-L4 hard cap.
- `weights.json` bumped to `9.0.0`: crime pillar now driven by `gpi_safety_security` (moved out of conflict); governance gains `vdem_rule_of_law` (moved out of crime); conflict gains the engine-injected synthetic `A` (advisory consensus) indicator; added per-indicator `subWeight`/`precision` and a `formulaV9` constants section (K/lambda/q/gamma/S_MAX/N_SEV/prior params/advisory tiers/exclusions/region offsets) — single source of truth the engine reads from, values ported verbatim from `final-constants.json`.
- `src/lib/regions.ts` extended from 199 to 241 of 248 tracked iso3 codes (adds RUS -> europe and ~40 other territories) sourced from `scores-extract.csv`; `engine.ts` now resolves region via `getRegion(iso3)` internally instead of a passed parameter.
- `backfill.ts`: added `vdem` to `YEAR_BASED_SOURCES` (historical vintage-per-file V-Dem data was being silently skipped by the fetchedAt-consistency gate); added `injectGpiForDate()` which selects the historically-correct GPI vintage (`year = min(snapshotYear, latest available year)`) from the date's own `gpi.xlsx` or, deterministically, the newest one across all `data/raw` dirs — for every one of the 668 snapshot dates, not just the 27 that happen to have their own `gpi.xlsx`.
- `gpi.ts`: added `parseGpiExcelAllYears()` (per-year indicators across all 3 GPI sheets, 2008-2023) and `selectGpiIndicatorsForYear()`; `fetchGpi`'s live `gpi-parsed.json` output is unchanged (latest-year, one value per country) so the daily pipeline is unaffected.
- Rewrote `engine.test.ts`, `crisis-validation.test.ts`, `weights-config.test.ts` for v9 mechanisms (shrinkage monotonicity, freshness-decay precision, prior collapse, region-dependent prior, severe-modifier bounds/count-damping, advisory continuity, acute down-only, confidence monotonicity) and updated all v8-structural assertions. Added an `npm test` script (`package.json`).
- Created `scripts/verify-formula-v9-parity.ts` (blocking parity gate) + committed the frozen ground-truth fixture `scripts/fixtures/formula-v9-parity-2026-07-06.csv`.
- Ran the full validation sequence: `npm test` -> parity gate -> `backfill --dry-run` (668/668 OK) -> live `backfill` (668/668 succeeded, rewrote every `data/scores/<date>.json` + `latest.json` + `history-index.json`) -> `cp data/scores/latest.json public/scores.json`.

- `npm test`'s glob pattern explicitly lists `src/pipeline/__tests__/*.test.ts` and `src/pipeline/scoring/__tests__/*.test.ts` rather than a single `src/pipeline/**/__tests__/*.test.ts` globstar, after discovering that macOS `/bin/sh` (npm's default script shell) treats `**` as a single-level wildcard that does **not** match zero intermediate directories — the naive globstar silently excluded `crisis-validation.test.ts`, `weights-config.test.ts`, `score-drift-guard.test.ts`, and the four `data0N-*.test.ts` files (all living directly under `src/pipeline/__tests__/`, zero levels below `pipeline/`).
