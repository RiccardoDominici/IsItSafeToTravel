<!-- D1 votes schema this plan authors. Extend the RESEARCH.md §Pattern 4 base with a second hash column for the per-visitor daily cap. -->
```sql
CREATE TABLE IF NOT EXISTS votes (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  iso3           TEXT    NOT NULL,
  delta          INTEGER NOT NULL,          -- -2..+2 (validated in the Function)
  official_score REAL,                      -- score shown at vote time (audit/context)
  voter_hash     TEXT    NOT NULL,          -- SHA-256(salt:ip:iso3:weekBucket) — per-country weekly dedupe; never raw IP
  day_hash       TEXT    NOT NULL,          -- SHA-256(salt:ip:dayBucket) — per-visitor daily volume cap
  created_at     INTEGER NOT NULL           -- unix epoch seconds, server time
);
CREATE INDEX IF NOT EXISTS idx_votes_iso3_created ON votes (iso3, created_at);
CREATE INDEX IF NOT EXISTS idx_votes_dedupe       ON votes (iso3, voter_hash, created_at);
CREATE INDEX IF NOT EXISTS idx_votes_daycap       ON votes (day_hash, created_at);
```
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/vote | Untrusted, unauthenticated public JSON POST crosses into the Pages Function |
| Function → D1 (env.DB) | Server-controlled prepared statements cross into edge SQLite |
| Function → Turnstile siteverify | Server-to-server over HTTPS with a server-held secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-01 | Tampering | SQL via iso3/delta | mitigate | Parameterized `env.DB.prepare(...).bind(...)` only; iso3 allowlist Set + isValidDelta before any query (Task 2) |
| T-39-02 | Tampering/Repudiation | Ballot stuffing | mitigate | Salted-hash weekly dedupe (voter_hash) + per-visitor daily cap (day_hash, DAILY_PER_VISITOR_CAP) + env-gated Turnstile |
| T-39-03 | Information Disclosure | Raw IP / PII | mitigate | SHA-256(salt+ip+scope) with weekly/daily buckets; raw IP never stored or logged (D-12/D-20); salt is a Pages secret |
| T-39-04 | Denial of Service | Free-tier write exhaustion | mitigate | Body-size cap (MAX_BODY_BYTES), single INSERT/vote, per-visitor daily cap, windowed dedupe SELECT; 100k writes/day headroom (D-16) |
| T-39-05 | Spoofing | Cross-origin/forged token abuse | accept/mitigate | Same-origin POST (`connect-src 'self'`); Turnstile hostname check available when enabled; accepted risk while Turnstile is env-off (documented, deferred user step) |
| T-39-06 | Tampering | Turnstile env-gated bypass | accept | When TURNSTILE_SECRET_KEY is unset, verification is skipped by design (D-12); rate-limit/dedupe still apply. Accepted until the user creates the widget. |
| T-39-07 | (operational) | Config-activation regression | mitigate | Keep existing compatibility_date/flags; post-deploy smoke test of `/` redirect + `/api/feedback` is an orchestrator manual verification (Pitfall 2) |
| T-39-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed this phase (RESEARCH Package Legitimacy Audit = empty); no install task exists |
</threat_model>
