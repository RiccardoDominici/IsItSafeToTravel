|----------|-------------|
| browser widget → /api/vote | Client-originated POST; validated server-side in 39-01 |
| Turnstile script/iframe → page | Third-party origin loaded only when explicitly enabled |
| localStorage → page state | Client-only soft dedupe; not authoritative, not a cookie |
